# PHP Student Management & User Authentication System

A simple PHP-based web application that provides user authentication, student data handling, and contact form functionality.  
This project demonstrates basic CRUD operations, session management, and form handling using core PHP and MySQL.

📌 Features

- User Registration & Login
- Session-based Authentication
- Logout functionality
- Insert and fetch student records
- User dashboard page
- Contact form data saving
- Basic PHP + MySQL integration
